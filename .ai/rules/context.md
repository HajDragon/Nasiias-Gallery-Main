# Project context: nastiia.gallery

Portfolio/gallery site for an artist. Public visitors browse and open artworks, like and comment (login required). Admins manage content in Filament. UI languages: `en`, `uk`.

Stack: Laravel 13, Filament 5 (admin), Inertia 3 + React 19, Tailwind 4, Pest/PHPUnit, spatie medialibrary (images), Fortify (auth, passkeys, 2FA), Telescope, activitylog. JS toolchain is `vp` (Vite+), package manager pnpm. Default branch `master`, but feature branches and PRs go through `Dev` (see general.md).

## Request flow (public site)

| URL                                                          | Controller@method                              | Inertia page                   |
| ------------------------------------------------------------ | ---------------------------------------------- | ------------------------------ |
| `/`                                                          | `HomeController@index`                         | `pages/welcome.tsx`            |
| `/gallery`                                                   | `GalleryController@index`                      | `pages/gallery/index.tsx`      |
| `/gallery/{artwork}`                                         | `GalleryController@show`                       | `pages/gallery/show.tsx`       |
| `/gallery/{artwork}` with `Accept: application/json`         | `GalleryController@show` (JSON)                | none, returns artwork detail   |
| `POST /gallery/{artwork}/like`, `/comments`; `GET /comments` | `GalleryController` (auth, throttled)          | JSON                           |
| `POST /contact`, `POST /locale/{locale}`                     | `ContactMessageController`, `LocaleController` | -                              |
| `settings/*`, `auth/*`                                       | Fortify + `Settings/*` controllers             | `pages/settings`, `pages/auth` |

Routes: `routes/web.php`, `routes/gallery.php`, `routes/settings.php`, `routes/notifications.php`.

## Artwork modal (important pattern)

Opening an artwork must NOT navigate; the modal is an overlay so scroll position and loaded-more state survive closing.

- `resources/js/components/ArtworkModal.tsx`: the modal UI (likes, comments, Esc/backdrop close). Exports `ArtworkModal` and `ArtworkDetail`.
- `resources/js/hooks/use-artwork-modal.ts`: `open(id)` fetches JSON from `/gallery/{id}`, `close()` clears. Falls back to `router.visit` if the fetch fails.
- Used by `welcome.tsx` and `gallery/index.tsx`. `gallery/show.tsx` is only the standalone page for direct links/SEO; its close goes to `/`.
- Do not `history.pushState` foreign state: Inertia's popstate handler reloads the page on state it did not write. The URL stays put while the overlay is open.
- `show()` records a view via `RecordArtworkViewAction` (deduped per session, ignores prefetch/HEAD).
- `resources/js/pages/home.tsx` is an older in-page-modal home. `HomeController` renders `welcome`, so check usage before editing it.

## Where things live

Backend (`app/`)

- Models: `Artwork`, `Category`, `Comment`, `Like`, `ArtworkView`, `ContactMessage`, `User`
- Actions (business logic, one invokable each): `app/Actions/` (`ToggleLikeAction`, `StoreCommentAction`, `RecordArtworkViewAction`, `ProcessArtworkImageAction`, `BuildMetricGrowthSeries`)
- `app/Http/Resources/ArtworkCardResource.php`: card payload (id, title, image_url, srcset, category)
- `app/Services/SEOService.php`: SEO data passed to every page as `seo`
- Admin: `app/Filament/Resources/{Artworks,Categories,Users}`, widgets in `app/Filament/Widgets`
- Middleware: `HandleInertiaRequests` (shared props), `SetLocale`, `SecurityHeaders`, `EnsureUserHasAdminRole`
- Commands: `GenerateSitemap`

Frontend (`resources/js/`)

- `app.tsx`: Inertia bootstrap; layout chosen by page name (add new pages to the switch)
- `pages/`, `layouts/` (`app`, `auth`, `site`, `settings`)
- `components/`: site components are PascalCase (`Header`, `FilterBar`, `Hero`, `ContactFooter`, `ArtworkHoverCue`, `ArtworkModal`); older shadcn-style ones are kebab-case; primitives in `components/ui/`
- `lib/i18n` (`useTranslation`, `t('group.key')`), strings in `lang/{en,uk}/*.php` (`app`, `ui`, `emails`, `validation`). Add every new string to BOTH languages.
- `routes/`, `actions/`, `wayfinder/`: generated by Wayfinder, never edit by hand

Styling: tokens in `resources/css/app.css`, see `css.md`. Fonts in `public/css/fonts.css`.

Tests (`tests/`): `Feature/` (e.g. `ArtworkInteractionTest`, `GalleryIndexTest`, `HomePaginationTest`), `Security/` (auth, uploads, headers, authorization), `Unit/`. Threat model: `docs/THREAT_MODEL.md`.

## Gotchas

- Homepage (`welcome.tsx`) has two layouts: a mobile snap-scroll feed (inner scroller, `sm:hidden`) and a desktop grid. Mobile double-tap = like, single tap (after 300ms) = open.
- "Load more" on `/` merges pages client-side into `visibleArtworks`; any full navigation to `/` loses it.
- Pins in `composer.json` (`symfony/*`, `spatie/image` exact version) are intentional.
- Anything touching auth, uploads or user data needs a test in `tests/Security`.
